# XML API

An XML synchronization engine that maintains full fidelity between source code and the Document Object Model (DOM).

This repository is managed as a pnpm workspace.
- [xml-api](./packages/xml-api): The main program distributed as `@miy2/xml-api` on npm. For more details, see the README in this directory.
- [xml-api-editor](./packages/xml-api-editor): A sample project currently being used for technical verification of xml-api
